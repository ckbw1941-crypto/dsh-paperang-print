# 喵喵机打印（实现细节）

把作业帮喵喵机 P2 HD 接到电脑上直接打印，不用再开手机 App。面板在左侧菜单「喵喵机打印」。

## 能做什么

- **打印文字**：写内容、选字号（默认 30），直接打印。
- **粘贴图片直接打印**：点「图片」卡片的虚线框按 `Ctrl+V`，或把图片文件拖进去，或点「从剪贴板读取」。全程不落盘，图片只在面板内存里。
- **灰阶开关**：开 = Floyd–Steinberg 抖动，照片过渡自然；关 = 纯黑白阈值（`< 128`），颗粒更粗、字更硬。
- **截图/文档模式**：阈值 `< 165`，截图、文档、表格笔画更清楚。
- **打印前预览**：按当前灰阶/文档/缩放/旋转设置二值化，显示 576 点宽的真实点阵、行数与毫米数；只转换不连打印机。
- **缩放与旋转**：20%–100% 缩放（内容变小、左右自动居中留白）；左转/右转 90°，把竖图横着打。
- **浓度与走纸**：浓度 0–100、尾部走纸 0–120 行，保存在 `settings.json`，面板打印和自动打印共用。
- **自动打印文件夹**：开启后监控 `待打印/`，稳定的图片/文本自动打印；成功移到 `已打印/`，失败进 `失败/`（同一文件最多试 20 次、每 30 秒一次）。守护进程是 `py/mmj_watch.py`，日志 `watch.log`。
- **打印机状态**：电量、固件版本、序列号、分辨率、纸张、上盖。

## 限制与前提

- 打印机必须开机、离电脑近，并且已经和这台电脑蓝牙配对过（只需一次）。
- 同一时刻只能有一个程序连着打印机：手机 App 连着时电脑连不上；自动打印运行中手动打印可能排队失败，重试即可。
- 纸宽 57mm，有效打印宽度 576 点（300dpi，约 48.8mm），图片等比缩到 576 宽。
- 实测环境是 Windows 11；底层 `bleak` 跨平台，macOS/Linux 未实测。
- 单次打印上限 12000 行。

## 安装与配置

装好后第一次要「准备打印环境」：在 `dataDir` 下建 venv 并安装 `bleak`/`Pillow`/`numpy`。配置项 `dataDir`、`pythonPath`、`address` 都可选，见 README。

## 实现链路

- 面板（浏览器）→ connection RPC `/paperang`（服务缺失时回落 Host 的 `webServer` 前缀路由 `/paperang/<method>`）→ Host `index.js` 用 `spawn` 起 `py/mmj_bridge.py`，**stdin** 传一行 JSON（图片 base64 很大，走 argv 会 `ENAMETOOLONG`）→ `py/mmj_print.py` 用 `bleak` 直连 BLE。
- A5 帧：`A5 01 | len(LE16) | payload | crc32(payload, seed 0x35769521)(LE32) | 5A`；payload = `command(BE16) | msgType(1=请求) | contentLen(LE16) | content`。
- 打印时序：`0x0511` 浓度 → `0x0520` 纸张类型 → `0x0519` 开始 → `0x051B` 位图块（序号递增，72 字节/行）→ `0x051A` 结束。开始到结束之间不插入状态查询；P2 HD 固件不逐块回 ack，写完成后等 0.8s 再发结束帧。
- 位图 MSB 在前、1 为黑。经典蓝牙 SPP 在这台机器上收到任意字节就断链，所以只走 BLE（`0000ff00-…`，写 `ff02`，通知 `ff01`/`ff03`）。
